# ReCircuit Project

ReCircuit is a platform that enables users to recycle their e-waste and reuse the components. The platform also offers a DIY project section and a marketplace to buy reused components.

## Project Structure

- `backend/app.py`: The Flask backend server
- `frontend/`: Frontend files containing HTML, CSS, and JS
- `models/schema.sql`: Database schema
- `database/components.db`: SQLite database
- `.env`: Environment variables
- `requirements.txt`: Python dependencies

## Setup Instructions

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Create the database schema: `python backend/models/schema.sql`
4. Run the Flask app
